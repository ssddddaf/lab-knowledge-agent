# 面试演示与答辩提纲

## 6 分钟演示

1. 展示论文 PDF 和由其生成的无文本层扫描版，说明页码、文件 SHA-256 与索引状态。
2. 问一个图表或公式相关问题，打开来源页面及检测到的区域；指出纯视觉命中只保证页面级定位。
3. 问一个跨两篇论文的比较题，展示 LangGraph 子任务、来源页与不同实验条件。
4. 提问一个资料中不存在的结论，展示“证据不足”、最多两轮补检及停止条件。
5. 打开模拟项目版本链，说明 r2 的输入、参数、产物和父运行记录。
6. 展示冻结测试集、对照实验结果及一例失败样本。没有实测数据时跳过“性能提升”表述。

## 追问要点

**为什么用 LangGraph？** 问题拆解后 `Send` 分发并行检索任务，reducer 合并证据；条件边控制校验与补检，checkpoint 保存图状态。节点应可重试且外部写入幂等，checkpoint 并不等同业务事务。

**ColQwen2 做了什么？** 它把整页图像编码成 patch 级多向量，Qdrant 以 MaxSim 做 late interaction。OCR/文本通道对术语与数值更经济，两者互补。页面向量无法直接给出精确图表边界，区域坐标来自版面解析。

**图谱有何价值？** 存储方法、数据集、实验、参数与证据关系，适合关系筛选和版本链。关系由模型抽取会出错，因此每条边保留证据 ID，并限制图查询模板和跳数。SQLite 中的项目记录是权威数据。

**校验能消除幻觉吗？** 不能。程序先检查引用存在、数字是否在来源中，再由独立模型判断语义支持与比较维度覆盖。矛盾或不足时补检，达到上限仍不支持就标注未知。最终仍靠人工标注集评测。

**如何比较论文结果？** 先核对数据集、指标定义、单位和实验条件；条件不一致时只陈述各自结果，不给出“更好”的强结论。

**可诚实陈述的当前状态：**代码已实现主要接口与工作流，SQLite 单元测试通过；云 GPU、多模态模型和外部数据库尚未在当前环境跑通，指标待测。简历日期与成果应在实际验证后更新。
