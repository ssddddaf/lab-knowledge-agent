# 实现边界与恢复策略

## 数据流

文档源文件以 SHA-256 存储。入库按页写 PNG、文本块和可选 OCR 块，再写 Qdrant 文本及视觉索引，最后把文档标记为 ready。失败时文档标记 failed，重试使用相同文档 ID 和确定性向量点 ID，重复 upsert 不产生另一份内容。

图谱从同一页证据抽取，关系需要 `document_id:page_number:block` 格式的证据 ID。抽取失败不影响基本搜索，但图谱补充结果可能缺失。项目记录独立于论文知识，始终标记 simulated。

查询先分解为至多四个子任务，每个子任务最多六页，合并后最多十二页。BM25、dense、visual、graph 的分数尺度不同，因此先在各路内部排序，再用 RRF 合并。视觉模型不可用时检索结果显式带降级标记。

## 当前限制

- API 的后台任务由 FastAPI 进程承载；进程中断会使任务停留在 running。生产化应改为持久任务队列和启动恢复扫描。
- OCR 坐标按当前 1.5 倍页面栅格比例还原。不同模型输出格式须在部署环境核验。
- 图谱抽取目前是逐页调用，可能较慢且有成本；建议先以少量论文测量。
- 语义校验模型可能犯错，不能把校验状态作为人工真值。
- 视觉与文本索引的实际规模、显存峰值和时延尚未测量。
